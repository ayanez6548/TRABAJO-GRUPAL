\dt

SELECT "Id", "Name", "UnitPrice", "UnitsInStock"

FROM "Orders" ORDER BY "Id" DESC LIMIT 5;

SELECT "OrderId", "ProductId", "UnitPrice", "Quantity"

Si eliges usar el modo alternativo PickupDirectory, el correo se guarda como
archivo .eml y no aparece en Mailtrap. Solo en ese modo usa el bloque siguiente:

[DEBIAN - TERMINAL]
Este bloque muestra el último mensaje local de PickupDirectory (puede ser antiguo):

python3 - <<'PY'
from pathlib import Path
from email import policy
from email.parser import BytesParser
import json
root = Path('/home/alex/NorthWind')
api = root / 'src/4. Frameworks And Drivers/UI/NorthWind.Sales.WebApi'
env = dict(line.split('=', 1) for line in (root / '.env.debian').read_text().splitlines() if '=' in line and not line.startswith('#'))
options = json.loads((api / 'appsettings.json').read_text()).get('SmtpOptions', {})
directory = Path(env.get('SmtpOptions__PickupDirectory', options.get('PickupDirectory', 'App_Data/mail')))
if not directory.is_absolute():
    directory = api / directory
files = list(directory.glob('*.eml'))
if not files:
    print('No hay mensajes locales en la ruta configurada. Revisa el modo de correo y guarda una orden con cuatro productos distintos.')
else:
    latest = max(files, key=lambda item: item.stat().st_mtime)
    message = BytesParser(policy=policy.default).parsebytes(latest.read_bytes())
    print('Archivo:', latest)
    print('Asunto:', message['Subject'])
    print(message.get_content())
PY

Debes poder mostrar: "Orden especial creada" y el número de la orden.

CAMBIOS PARA DEMOSTRAR EN LOS FILTROS Y VALIDACIONES:
- En "Filtrar por", elegir el campo: solo se muestra la entrada seleccionada.
- Los filtros anteriores siguen activos como etiquetas. Pulsar su × quita solo ese filtro.
- Clientes: combinar código, nombre y saldo mínimo/máximo.
- Productos: combinar código, nombre, precio y existencias mínimas/máximas.
- Limpiar restablece todos los filtros; Anterior/Siguiente conserva los aplicados.
- Quitar muestra confirmación: Cancelar y Escape conservan el producto; Sí, quitar lo retira.
- Correo: máximo 30 caracteres en login y registro; una arroba, sin espacios; símbolos . _ - +.
- Nombres y apellidos: máximo 30 caracteres.
- Contraseña y confirmación: sin máximo de longitud impuesto por la aplicación; registro conserva el mínimo de 6 caracteres, mayúscula, minúscula, número y símbolo.

BUSQUEDA AUTOMATICA Y AVISOS:
- Escribe en código, nombre, importes o existencias: la lista se actualiza al dejar de escribir durante 400 ms. No es obligatorio pulsar Buscar.
- Si cambias el filtro mientras llega una consulta anterior, se conserva el resultado de la consulta más reciente.
- Limpiar cancela la búsqueda pendiente y restablece los resultados.
- Los errores de formularios, rangos y caracteres no permitidos muestran una ventana al frente con Entendido.
- Las advertencias se muestran solo en una ventana al frente con Entendido o Escape.
- Los errores se agrupan sin repetir mensajes; no hay resúmenes rojos arriba del formulario ni globos del navegador.

HISTORIAL DE FACTURAS:
- Iniciar sesión y abrir Facturas: se listan las ventas guardadas por esa cuenta,
  de la más reciente a la más antigua, con fecha UTC, cliente, productos y total.
